## 新增 / Added
- 无线连接对话框新增异步 ADB 服务状态检查：可用时显示绿色圆点和服务端点，异常或超时显示红色并建议点击“重启 ADB 服务”，每 5 秒及用户确认重启后刷新，关闭对话框时停止检查。
  The wireless dialog now checks the ADB server asynchronously: a green dot and the server endpoint when it responds, a red dot with a restart suggestion on failure or timeout, refreshed every five seconds and after a confirmed restart, and stopped when the dialog closes.
- 检查通过只读的 ADB `host:version` 协议请求完成（新增 `adb_status.py`），端点遵循 `ADB_SERVER_SOCKET` / `ANDROID_ADB_SERVER_ADDRESS` / `ANDROID_ADB_SERVER_PORT`，默认 `localhost:5037`；检查本身不会启动、重启或终止 ADB 服务。
  The check is a read-only ADB `host:version` protocol request (new `adb_status.py`) against the endpoint from `ADB_SERVER_SOCKET` / `ANDROID_ADB_SERVER_ADDRESS` / `ANDROID_ADB_SERVER_PORT`, defaulting to `localhost:5037`; it never starts, restarts or kills the ADB server.
- `AGENTS.md` 记录该行为要求，以及“每个分支必须把最终变更写入 `changelogs/`”的发布规约。
  `AGENTS.md` now documents this behaviour and the release rule that every branch must record its final changes under `changelogs/`.
