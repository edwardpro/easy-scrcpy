## 新增 / Added

- 跨平台 scrcpy 托盘助手：设备面板 + 系统托盘常驻（macOS 菜单栏、Windows / Ubuntu 托盘），关闭主窗口后继续运行，并有单实例保护。/ Cross-platform scrcpy tray companion: device panel plus a persistent tray icon (macOS menu bar, Windows / Ubuntu tray); the app keeps running after the window closes, with single-instance protection.
- 内置 scrcpy 5.0 与 ADB 37.0.1 及配套文件，打包产物无需另行安装 Python、scrcpy 或 ADB。/ Bundles scrcpy 5.0, ADB 37.0.1 and companion files, so packaged apps need no separate Python, scrcpy or ADB install.
- USB 设备检测：设备授权后询问是否开始投屏；ADB 查询失败或超时时保留既有设备状态。/ USB device detection: asks whether to start mirroring once a device is authorized, and keeps the previous device state when an ADB query fails or times out.
- 多设备独立窗口投屏，可单独停止或全部停止；拔线 / 离线自动停止对应进程。/ Mirrors several phones in independent windows with per-device or global stop; unplugging or losing a device stops only its own process.
- 每设备画质：流畅、标准、高清、自定义或跟随全局，可调分辨率上限、帧率与视频码率；修改画质只重启该设备的投屏，不走关闭 USB 调试流程。/ Per-device quality: Smooth, Standard, High, Custom or Global, with resolution cap, frame rate and video bit rate; changing quality restarts only that device and never touches USB debugging.
- 可选的“停止时关闭 USB 调试”，默认关闭，仅在用户显式启用且手动 Stop 时生效。/ Optional “disable USB debugging on stop”, off by default and only applied on an explicit manual Stop.
- 五语言界面（英语、简体中文、法语、德语、日语），自动检测系统语言并支持即时切换。/ Five languages (English, Simplified Chinese, French, German, Japanese) with system-language detection and live switching.
- 开机自启（macOS、Windows、Ubuntu）。/ Optional startup at login on macOS, Windows and Ubuntu.
- 诊断能力：设备状态、有界日志、错误提示与日志文件。/ Diagnostics: device status, bounded in-app logs, error messages and a log file.
- 工程配套：带 SHA-256 校验与回滚的依赖更新脚本、三平台 GitHub Actions 测试与手动打包工作流、unittest 与无界面 Qt 集成测试、README 与 wiki 截图、`RELEASE_NOTES.md`。/ Engineering: a dependency update script with SHA-256 verification and rollback, three-platform GitHub Actions tests plus a manual packaging workflow, unittest and offscreen Qt integration tests, README with wiki screenshots, and `RELEASE_NOTES.md`.

## 修复 / Fixed

- Windows 构建统一使用 UTF-8（`PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8`，文件读写显式指定编码），避免 CP1252 崩溃；GitHub Actions 升级到 Node 24。/ Windows builds now force UTF-8 (`PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`, explicit encodings on file I/O) to avoid CP1252 crashes, and GitHub Actions were upgraded to Node 24.
- 保留 Windows 上游 scrcpy 的 `LICENSE.txt` 原件，并额外生成统一的 `LICENSE` 副本。/ Keeps the upstream Windows scrcpy `LICENSE.txt` intact and additionally emits a unified `LICENSE` copy.
