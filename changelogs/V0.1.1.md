## 新增 / Added

- 自定义应用图标与托盘图标（`assets/icon.png`、`assets/tray-icon.png`），打包时按平台生成所需尺寸。/ Custom application and tray artwork (`assets/icon.png`, `assets/tray-icon.png`), converted per platform during packaging.
- 设备插入通知：Windows toast 与 macOS UserNotifications，带“重新开始 / 停止 / 设置”操作；Ubuntu 不启用可操作通知。通知失败不影响设备检测与应用启动。/ Device notifications via Windows toasts and macOS UserNotifications with restart / stop / settings actions; actionable notifications stay disabled on Ubuntu, and a failing backend never breaks device detection or startup.
- 通知操作使用连接级标识并经 Qt 信号切回主线程，设备断开后旧通知不会误控新连接。/ Notification actions carry a per-connection token and are marshalled back to the main thread, so a stale notification cannot control a reconnected device.
- 开发规约 `AGENTS.md` 与 `.coding/` 迭代记录目录（需求、设计、验证与失败记录随源码保留）。/ Development guidelines in `AGENTS.md` plus the `.coding/` iteration-record directory (requirements, design, verification and failed attempts are kept in Git).
- 画质与参数控件改为预设下拉选项，Start / Stop / 画质按钮统一为 40×40（图标 24×24，设备行至少 56 px），保留多语言 tooltip 与 accessible name。/ Quality and parameter controls became preset dropdowns, Start / Stop / quality buttons were standardised at 40×40 (24×24 icons, rows at least 56 px) and keep translated tooltips and accessible names.

## 修复 / Fixed

- macOS 托盘改用单色模板图标 `tray-icon-mac.png`，在深浅色菜单栏下都正确显示；其他平台继续使用彩色图标。/ The macOS tray now uses the monochrome template icon `tray-icon-mac.png` so it renders correctly in both light and dark menu bars, while other platforms keep the colored icon.

## 变更 / Changed

- 参数控件不再提供自由数值输入；旧的有效值会作为额外选项保留，配置向后兼容。/ Free numeric input was removed from parameter controls; previously stored valid values are kept as extra options, so existing configs stay compatible.
